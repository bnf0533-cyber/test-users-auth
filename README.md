הרצה

```
git clone https://github.com/bnf0533-cyber/test-users-auth.git
```

## .env

למלאות את הנתונים שצריך

```
PORT = enter your port
MONGO_URL= enter url to mongodb
SECRET_JWT= enter your secret token
JWT_TIM= enter your time to live your token
```

# הוראות הרצה

```
cd backend
npm init -y
npm i
npm start
cd ..
cd frontend
npm init -y
npm i
npm run dev
```
